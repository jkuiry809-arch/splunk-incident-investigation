# Splunk Incident Investigation Labs

## 1. Overview
This repository contains practical labs, Splunk Search Processing Language (SPL) queries, and incident investigation workflows developed as part of the **Cover6 First Watch** training program. The primary focus is on hands-on Security Information and Event Management (SIEM) operations, log analysis, threat detection, and incident response.

---

## 2. Core Focus Areas
* **Log Parsing & Analysis:** Examining authentication logs, web server traffic, and system telemetry to identify anomalies.
* **SPL Querying:** Utilizing advanced Splunk search operators (`stats`, `eval`, `rex`, `transaction`, `timechart`) to extract insights from raw data.
* **Threat Detection:** Investigating simulated attack patterns, such as brute-force attempts, lateral movement, and unauthorized access.
* **Dashboard Creation:** Building custom panels and visualizations for continuous monitoring.

---

## 3. Repository Structure
* **`queries/`** - Reusable SPL query snippets categorized by use case (e.g., authentication tracking, network telemetry analysis).
* **`scenarios/`** - Case studies and step-by-step breakdowns of simulated incident investigations.
